Privacy Policy: Surf N Slides Meta application

Effective 6 November 2026

1. Who we are

Surf N Slides operates an indoor FlowRider surfing venue on Corniche Beach, Abu Dhabi, United Arab Emirates (website: www.surfnslides.com). This policy covers the Meta developer application named Surf N Slides (the "App"). It does not cover our venue bookings or our website, which have their own terms.

2. What the App does

The App is an internal business tool. It publishes Surf N Slides' own, pre-approved marketing content (photos, carousels, Reels and Stories) to the Surf N Slides Instagram professional account @surfnslide.uae on a fixed schedule, and it checks that those posts were published correctly.

  • It connects only to the Instagram professional account and the linked Facebook Page that Surf N Slides owns, through a Meta Business system user.
  • It does not offer Facebook Login or Instagram Login to the public, and members of the public cannot sign in to it.
  • It does not run advertising, send messages, or read private messages.

3. Information the App accesses

Through the Instagram Graph API, and only for the Surf N Slides account, the App reads:

  • Account details: account ID, username, display name, follower count and post count, to confirm it is connected to the right account.
  • Details of posts on the Surf N Slides account: post ID, caption, publication time, link, media type, like count and comment count. These are used to prevent duplicate posts, confirm that scheduled posts went live, and produce internal performance reports.
  • The account's daily content-publishing limit, to stay within Instagram's limits.

The App does not collect the names, profiles, comments or messages of other Instagram or Facebook users. Like and comment counts are totals only. The App does not use cookies or tracking technologies, and does not collect data from visitors to these web pages.

4. Permissions requested from Meta

  • instagram_basic: read the Surf N Slides account profile and its posts.
  • instagram_content_publish: publish Surf N Slides' own scheduled content to that account.
  • pages_show_list: identify the Surf N Slides Facebook Page that is linked to the Instagram account.

5. How information is stored and for how long

  • Publishing records (post schedule key, status, Instagram post ID, link, publication time and any error message) are stored in a private GitHub repository controlled by Surf N Slides. They are kept as business records of our own social media activity for as long as the automation is in use, and they are deleted on request (see Section 8).
  • Monitoring alerts and reports (publishing status, post counts, like and comment totals) are stored as issues in the same private repository.
  • Run logs are kept by GitHub Actions under GitHub's standard log retention, which is 90 days by default.
  • Access credentials issued by Meta are stored only as encrypted GitHub Actions secrets. They are never written to logs, files or reports.

6. Service providers

  • Meta Platforms (Instagram Graph API): receives the content we publish and returns the account information described above.
  • GitHub (Microsoft): hosts the private repository and runs the scheduled automation.
  • Cloudflare: during each publishing run, a temporary, randomly addressed link serves only that run's approved image or video files to Meta, which needs a public link to fetch media. The link stops working when the run ends. Only the approved marketing files being published in that run pass through it.

We do not sell, rent or share information from the App with advertisers or data brokers, and we do not use it for advertising.

7. Security

  • Credentials are held as encrypted secrets with access limited to the repository owner.
  • The repository is private.
  • Logs mask credentials and temporary addresses.
  • Every publication is checked against a ledger and against the account's existing posts to prevent duplicates.

No system is completely secure, but we limit the App to the minimum data and permissions it needs.

8. Your choices and data deletion

The App only processes data about the Surf N Slides business account. If you believe it holds information about you, or you want data deleted, follow the Data Deletion Instructions or contact us below.

9. Changes to this policy

We will update this page if the App's data handling changes. The effective date above shows the latest version.
